
# AI Resume Analyzer & ATS Scoring System

An AI-powered resume analysis application built using Python, Streamlit, NLP and Machine Learning.

## Features

- PDF Resume Extraction
- AI Semantic Similarity Matching
- ATS Match Score Calculation
- Technical Skill Extraction
- Missing Keyword Detection
- Resume Section Analysis
- Resume Improvement Recommendations
- Downloadable ATS Analysis Report

## Technology Stack

- Python
- Streamlit
- Sentence Transformers
- Scikit-learn
- PyPDF
- NLP
- Machine Learning

## How to Run Locally

1. Clone the repository.
2. Create a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   streamlit run app.py

## AI Model

all-MiniLM-L6-v2

## Disclaimer

The ATS score is an experimental matching score and is not an official ATS evaluation.
